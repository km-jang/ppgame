# 슥슥 우주 다리 기획서 (1단계, 2026-09-29)

소유자 결정 (2026-09-29): "1단계 진행해, 이름은 그대로, 플랑크로".
기획 초안은 저장소 최상위 `NEW-GAME.md`의 E안. 목업 그림을 보고 이 방향으로 정했다.

## 1. 한 줄

손가락으로 그린 선이 그 모양 그대로 진짜 물건이 되어 떨어지고 구른다. 그 선으로 다리를 놓아 공 캐릭터(데굴이)를 외계인 친구에게 데려다준다.
정답이 하나가 아니라 아이마다 다른 방법으로 풀 수 있다. 지는 화면 없음.

## 2. 한 판의 흐름

1. 판이 열리면 공과 물건은 멈춰 있고, 친구가 말풍선으로 부른다 ("여기야!")
2. 화면에 선을 그린다. 손을 떼는 순간 선이 굳어 물건이 되고 물리가 돌기 시작한다 (그 뒤에도 더 그릴 수 있다)
3. 공이 친구에게 닿으면 "만났다!": 하트·색종이, 별 1 ~ 3개
4. 공이 화면 밖으로 떨어지면 "앗! 다시 해 볼까요?" 뒤 0.9초 만에 저절로 처음부터 (선 지움, 잉크 가득)
5. 공이 3초 넘게 멈춰 있으면 "막혔나요? 되돌리기나 다시 하기를 눌러요"

## 3. 조작

| 하는 것 | 결과 |
|---|---|
| 쭉 긋기 | 선 (점 사이 10px 이상, 손 떨림을 두 번 다듬어 부드럽게) |
| 톡 누르기 | 작은 구슬 (반지름 13px, 미끄러움) |
| 땅·바위·공 속으로 긋기 | 그 부분은 그려지지 않는다. 빈 곳으로 돌아오면 이어서 |
| 되돌리기 버튼 | 마지막 선 지우기, 잉크 돌려받음 |
| 다시 버튼 | 처음부터 |
| 전구 버튼 | 정답 선을 점선으로 5초 (공이 두 번 떨어지면 전구가 반짝) |
| 판 고르기 버튼 | 판 고르기 화면 |

- 한 번에 손가락 하나만 그린다. 손바닥(닿은 넓이 70px 초과)은 무시.
- PC: 마우스로 긋기, `Z` 되돌리기, `R` 다시, `M` 소리.

## 4. 잉크와 별

- 판마다 정답 선 길이(`sol`)로 정한다 (`data.js` `D.INK`).
  - 잉크 전체 = 정답의 3.4배 (최소 700px)
  - 별 3개 = 쓴 잉크가 정답의 1.45배 이하
  - 별 2개 = 2.2배 이하
  - 별 1개 = 깨기만 하면
- 잉크는 그린 그대로의 길이로 센다 (다듬기로 짧아져도 도로 늘지 않는다).
- 잉크 막대 아래 별 두 개가 "여기까지 쓰면 별이 하나 준다" 눈금이다.

좌표는 논리 크기 1280×800. 화면에 통째로 맞춰 늘리고 남는 곳은 하늘·땅을 이어 그린다.

| 달 2 | 넓은 골짜기 | 긴 다리 |
| 달 3 | 떨어지는 공 | 떨어지는 공을 받는 미끄럼틀 |
| 달 4 | 두 골짜기 | 기둥을 딛는 긴 다리 |
| 달 5 | 오르막 | 비탈에서 턱 위로 오르는 다리 |
| 달 6 | 구멍 두 개 | 굴러오는 공, 구멍 덮기 |
| 달 7 | 바위 넘기 | 큰 바위를 넘는 다리 |
| 달 8 | 톡 밀기 | 구슬을 떨어뜨려 공을 밀기 (처음 안내) |
| 달 9 | 떨어지고 건너기 | 떨어진 공이 굴러 다리로 |
| 달 10 | 골짜기와 언덕 | 휘어진 선 (내려갔다 올라가기) |
| 화성 1 | 스프링 첫 만남 | 다리 끝의 스프링이 높은 곳으로 |

| 화성 4 | 상자 디딤돌 | 움직이는 상자를 딛는 다리 |
| 화성 5 | 두 번 튕기기 | 스프링 두 개 |
| 화성 6 | 바위 사이 | 바위 두 개를 넘는 다리 |
| 화성 7 | 얼음 오르막 | 얼음 비탈에서 턱 위로 |
| 화성 8 | 바위 받침 | 얼음 비탈, 바위를 딛는 다리 |
| 화성 9 | 스프링 다리 | 다리로 스프링까지 |

- 모든 판은 테스트가 정답 선을 그려 풀리는지, 아이 손처럼 흔들린 선 12개 중 8개 이상 풀리는지, 선 없이는 안 풀리는지 확인한다.

### 판 만드는 법 (다음 판을 더할 때)

1. `data.js`에 `add('행성', {...})` 한 줄. `ground`(윗면 점 목록), 필요하면 `rocks`·`boxes`·`seesaws`·`springs`, `ball`·`goal`·`say`·`sol`.
2. 선이 땅 모서리를 스치면 그 부분은 안 그려진다. 정답 선의 한가운데가 땅 위로 8px 이상 떠 있게.
3. 선 끝이 땅에 걸치는 길이가 짧으면 미끄러져 떨어진다. 양쪽 끝이 땅 위에 넉넉히(50px 안팎) 걸치게.
4. 선 양 끝에는 비탈이 붙어(아래 6절) 공이 땅에 누운 선에 턱 없이 올라탄다. 끝이 가파르거나(가로 성분 0.5 미만) 비탈 자리가 막히면 비탈이 없으니, 그런 끝에 공이 정면으로 부딪히게 짜지 않는다.
5. `node tests/bridge.test.js`로 확인.

## 6. 물리 (Planck.js)

- `lib/planck.min.js`: Planck.js 1.5.0 (Box2D를 자바스크립트로 옮긴 물리 엔진, MIT, 무료). 고지는 `lib/LICENSE.md`.
- 40px = 1m, 중력 14m/초², 1/60초 고정 간격 (화면 주사율과 상관없이 같은 결과, 테스트가 30·60·120·144Hz로 확인).
- 그린 선 = 몸체 하나에 네모 조각(마디마다) + 둥근 이음매(점마다) + 양 끝 비탈(세모). 굵기 10px (2026-09-29 14px에서 줄임).
- 비탈 (2026-09-29 소유자 태블릿 확인 "너무 굵어서 걸려"): 아래 면은 선 그대로 이어지고 위 면만 끝으로 갈수록 내려와 44px 뒤 두께 0. 끝 20px 앞 점으로 방향을 재고, 끝이 가파르면(가로 성분 `rampFlat` 0.5 미만) 없음, 비탈 끝이 땅 속이거나 가는 길이 막히면 22px로 줄이고 그래도 막히면 없음. 잉크는 들지 않는다. 평지에서 땅에 누운 선을 넘는 공의 속도(선 앞 대비 선 위 최저): 14px 비탈 없음 47.8%, 10px 비탈 없음 58.7%, 10px 비탈 있음 92.7% (시험 `lipKeep`). 화면의 빛 번짐도 선 굵기보다 10px 넓게로 줄임(예전 14px).
- 땅은 속이 빈 테두리(chain)라 볼록하지 않은 모양도 된다.
- 공은 빠른 물체(bullet)로 얇은 선을 뚫지 않게. 처음부터 구르는 공(`push`)은 굴러가는 회전도 같이 준다.
- 수치는 모두 `data.js` `D.PHYS`.
