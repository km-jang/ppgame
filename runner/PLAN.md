# 슝슝 우주 달리기 기획서

> 2026-09-27 첫 빌드. 냠냠 뱀과 같은 구조·글꼴·네온 느낌의 끝없는 줄 달리기 게임.

## 1. 한 줄 요약

뿅뿅 우주선 가족인 청록 우주선이 네온 격자 우주 길을 저절로 날아간다. 세 줄 사이를 옮겨 다니며
빨간 운석을 피하고, 레이저 문은 뛰어넘고, 별을 모은다. 오래 갈수록 조금씩 빨라진다.

## 2. 원칙

| 항목 | 결정 |
|---|---|
| 대상 | 아이들 (게임 오버 있음, 쉬움이 기본) |
| 기기 | 갤럭시탭 가로(1280×800) 우선, 작은 탭(893×533)·세로 폰·PC도 |
| 기술 | 바닐라 JS + Canvas 2D, 빌드 없음, `file://`로도 실행. 이름공간 `RN` |
| 에셋 | 그림·소리 파일 0개. 도형으로 그리고 소리는 WebAudio 합성 |
| 외부 | 구글 글꼴(주아 Jua · Rajdhani)만 |
| 저장 | 기록 장부 `runner.rec`, 난이도 `runner.easy`, 음소거 `runner.muted` |
| 오프라인 | `sw.js` 저장본 이름 `runner-v1`. 옛 저장본은 `runner-`로 시작하는 것만 지운다 |

## 3. 화면

- 앞을 내다보는 원근 화면: 지평선의 큰 해·고리 행성·별 하늘, 빛나는 격자 바닥 위 세 줄 길.
- 물체는 지평선에서 작게 나타나 다가올수록 커진다. 규칙 파일은 줄 번호와 거리(m)만 쓰고, 원근은 `render.js`가 한다.
- 위쪽 줄: 일시정지 · 소리 · 전체 화면 버튼, 오른쪽에 거리(m)와 하트·별·방패·효과 남은 시간·최고 기록.
- 시작 화면 뒤에서는 자동 운전 우주선이 달린다.

## 4. 조작

| 입력 | 동작 |
|---|---|
| 화면 아무 데나 옆으로 밀기 | 줄 바꾸기 (냠냠 뱀과 같은 손맛: 기준 거리마다 다시 재고, 빠른 튕기기도 알아듣는다) |
| 화면 왼쪽 3분의 1 · 오른쪽 3분의 1 누르기 | 한 줄 왼쪽 · 오른쪽 |
| 위로 밀기 · 가운데 누르기 | 점프 |
| 키보드 | ← → 또는 A D 줄 바꾸기, ↑ W 스페이스 점프, P 일시정지, M 소리 |

민(누른) 자리에 노란 화살표가 잠깐 뜬다. 떠 있을 때 누른 점프는 잠깐 기억했다가 닿자마자 뛴다.

## 5. 장애물 · 아이템 (수치는 `js/data.js`)

| 종류 | 모양 | 규칙 |
|---|---|---|
| 운석 | 빨간 테두리·빨간 빛무리 바위, 바닥에 빨간 판 | 줄 하나를 막는다. 점프로 못 넘는다 |
| 레이저 문 | 빨간 레이저 두 줄 + 바닥 노랑·검정 줄무늬 | 점프하면 넘는다. 위에 별 무지개가 있을 때도 있다 |
| 움직이는 운석 (보통만) | 운석 + 빨간 꺾쇠 | 40m 앞까지 오면 옆 줄로 미끄러진다 |
| 별 | 노란 네 갈래 별 | 10점. 이어 먹으면 소리가 한 계단씩 오른다 |
| 방패 | 청록 방패 | 한 번 부딪혀도 괜찮다 |
| 자석 | 분홍 자석 | 7초 동안 모든 줄의 별을 끌어온다 |
| 부스트 | 노란 번개 | 4초 동안 1.7배 빠르고, 부딪히는 것을 부순다, 별 비 |

- 아이템은 나타날 때부터 이름표가 붙어 좋은 것임을 알 수 있다. 늘 안전한 줄에 놓인다.
- 지금 줄 바로 앞 장애물 위에 "위험!"(운석) · "점프!"(레이저 문) 말풍선.
- **어떤 줄이든 장애물이 없는 줄이 하나 이상** 남고, 줄 사이 간격은 가장 빠를 때도 두 줄을 건너갈 시간보다 길다 (테스트로 확인).

## 6. 쉬움 · 보통

| | 쉬움 (기본) | 보통 |
|---|---|---|
| 속도 (초당 m) | 13에서 천천히 22까지 | 17에서 32까지 |
| 장애물 간격 | 1.6~2.4초 | 1.0~1.6초 |
| 하트 | 3개 (부딪히면 하나 잃고 잠깐 깜빡이는 동안 무적) | 1개 (방패로 한 번 버틴다) |
| 움직이는 운석 · 문 둘 | 없음 | 있음 |

점수 = 달린 거리(m) + 별 × 10.

## 7. 메달 12개 (동·은·금)

첫 비행(500m) · 먼 우주(1,500m) · 은하 끝까지(3,000m) · 별 50 · 별 150 · 폴짝폴짝(레이저 문 10번) · 튼튼 방패 ·
슝슝슝(부스트 3번) · 무사고 비행(안 부딪히고 1,000m) · 보통도 거뜬(보통 1,000m) · 단골 조종사(10판) · 별 부자(모두 1,000개).
메달·기록 화면에 최고 거리·점수·한 판 최고 별·모두 한 판·모은 별·모두 달린 거리.

## 8. 파일

| 파일 | 역할 |
|---|---|
| `js/util.js` | 이름공간 `RN`, 시드 난수, 저장소 |
| `js/data.js` | 모든 수치 (속도·간격·점프·아이템·메달·연출) |
| `js/world.js` | 규칙 (DOM 없음, `tests/runner.test.js`). 1/120초 칸으로 돌아 60·90·120Hz에서 결과가 같다. 자동 운전 `bot` |
| `js/render.js` | 원근 그리기. 하늘·길은 미리 그려 두고, 발광은 미리 그린 스프라이트 (매 프레임 shadowBlur 없음), 입자 160개 제한 |
| `js/input.js` · `js/audio.js` · `js/main.js` | 밀기·누르기·키보드 · 합성 소리 · 화면 흐름 (최대 초당 60번 그림) |

움직임 줄이기 설정이면 흔들림·번쩍임·빛줄기·별 흔들림을 건너뛴다.
테스트용 손잡이 `RN.debug`: `world` `mode` `rec` `easy` `setEasy` `newGame(seed, opts)` `pause` `resume` `toTitle` `openMedals` `move(dir)` `autopilot(on)`.
