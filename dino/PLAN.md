# 뚝딱 로봇공룡 기획서

> 2026-09-24 초안. 대상: 5~6세 남자아이. 기기: 갤럭시탭 (터치 전용).
> N-GUN과 같은 기술(바닐라 JS + Canvas, 파일 0개 합성음)을 그대로 쓴다.

## 1. 한 줄 요약

부품을 끼워 **나만의 로봇 공룡**을 만들고, 그 공룡을 타고 정글·화산·바다를 달리며 별을 모아
**스티커**와 **새 부품**을 얻는 게임. 지는 일은 없고, 부딪히면 웃긴 일이 일어난다.

## 2. 왜 이 주제인가

| 5~6세 남자아이가 좋아하는 것 | 이 게임에서 |
|---|---|
| 공룡, 로봇, 탈것 | 셋을 합친 "로봇 공룡". 바퀴·제트팩·드릴을 단 티라노 |
| 내가 만든 것 자랑하기 | 조립한 공룡이 그대로 주인공이 된다. 사진 찍기 화면 |
| 부수기, 쿵쾅거리기 | 상자·바위·얼음을 부순다 (생물은 부수지 않는다) |
| 모으기 | 스티커북 30칸, 부품 해금 |
| 같은 걸 반복하기 | 한 판 1~2분, 끝나면 바로 다시 |

만들기(창의)와 달리기(액션)를 번갈아 하게 해서 한쪽에 금방 질리지 않게 한다.

## 3. 설계 원칙 (이 나이에 맞추기)

1. **글자 없이 진행.** 모든 안내는 그림과 목소리로 한다. 목소리는 태블릿에 들어 있는 한국어
   음성 읽기 기능(브라우저 speechSynthesis)을 써서 파일 없이 낸다. 예: "초록 버튼을 눌러 봐!"
2. **지는 일이 없다.** 체력·게임 오버가 없다. 구덩이에 빠지면 공룡이 "뿅" 하고 튀어나와 계속 달린다.
   못 모은 별만 아쉬울 뿐이다.
3. **버튼은 크게, 개수는 적게.** 터치 영역은 최소 손가락 두 개 폭(약 90px). 게임 중 버튼은
   "화면 아무 데나 누르기" + "큰 능력 버튼 1개"가 전부.
4. **누르면 무조건 반응.** 모든 터치에 소리와 움직임을 준다. 아무 의미 없는 곳을 눌러도
   풀이 흔들리거나 새가 날아간다.
5. **무섭지 않게.** 밝은 색, 둥근 모양, 웃는 얼굴. 악당 대신 "장난꾸러기 원숭이 로봇"이 길을 막는다.
6. **보호자가 안심하게.** 광고·결제·외부 링크·데이터 수집 없음. 하루 사용 시간 제한.

## 4. 게임 흐름

```
[차고] 부품 고르기 → [지도] 갈 곳 고르기 → [달리기] 1~2분 → [결과] 별 세기·스티커 받기 → [차고]
```

### 4.1 차고 (조립 화면)
- 화면 가운데에 공룡 뼈대. 아래에 부품 서랍 3칸 (머리 · 다리 · 등 장비).
- 부품을 **누르기만 하면** 공룡에 "철컥" 붙는다 (끌어다 놓기는 이 나이에 어렵다. 끌어도 되지만 필수는 아님).
- 색칠 통 6개: 누르면 몸통 색이 바뀐다.
- 다 만들면 공룡이 포효하며 폴짝 뛴다. "사진 찍기" 버튼으로 차고 벽에 걸어 둔다 (최근 6장).

### 4.2 부품과 능력 (처음 9개, 뒤에 해금)

| 칸 | 부품 | 달리기에서 |
|---|---|---|
| 머리 | 티라노 | 능력 버튼 = 크게 포효, 앞의 상자가 다 날아감 |
| 머리 | 트리케라톱스 | 능력 버튼 = 박치기 돌진, 바위 부수기 |
| 머리 | 프테라노돈 | 능력 버튼 = 새 친구들이 날아와 별을 물어다 줌 |
| 다리 | 공룡발 | 쿵쿵 걸음, 착지할 때 땅이 흔들려 나무에서 과일(보너스 별)이 떨어짐 |
| 다리 | 바퀴 | 가장 빠름, 비탈에서 붕 뜸 |
| 다리 | 스프링 | 가장 높이 뜀 |
| 등 | 제트팩 | 누르고 있으면 천천히 떠오름 |
| 등 | 날개 | 점프 뒤 누르고 있으면 활공 |
| 등 | 드릴 꼬리 | 땅속 지름길로 파고듦 |

**어떤 조합으로도 끝까지 갈 수 있다.** 맞는 부품이 있으면 지름길이나 보너스 별이 생길 뿐이다.
그래서 아이가 "이번엔 드릴 달고 가 볼래!" 하며 같은 곳을 다시 달리게 된다.

### 4.3 지도 (갈 곳 고르기)
큰 그림 5개가 이어진 섬 지도. 지난 곳은 별 개수가 표시되고, 다음 곳은 열쇠 모양으로 잠겨 있다.

| 곳 | 분위기 | 장애물 | 어울리는 부품 |
|---|---|---|---|
| 정글 | 초록, 폭포 | 나무 상자, 덩굴 | 티라노·공룡발 |
| 화산 | 주황, 용암 방울 | 바위, 뜨거운 웅덩이(점프) | 트리케라·스프링 |
| 바다 섬 | 파랑, 징검다리 | 끊긴 다리, 파도 | 날개·제트팩 |
| 눈산 | 하양, 미끄럼 | 얼음 벽, 눈사람 | 드릴·바퀴 |
| 우주 (보너스) | 보라, 별똥별 | 낮은 중력 | 전부 |

### 4.4 달리기
- 공룡은 오른쪽으로 **저절로** 달린다 (속도는 느긋하게).
- **화면 아무 데나 누르기** = 점프 (제트팩·날개면 누르고 있기 = 떠오르기·활공).
- **오른쪽 아래 큰 능력 버튼** = 머리 부품 능력. 쓸 수 있을 때 반짝이며 흔들린다.
- 별 모으기 + 가끔 공룡 알. 끝에 깃발을 지나면 불꽃놀이.
- 장난꾸러기 원숭이 로봇이 가끔 바나나 껍질을 던진다. 밟으면 공룡이 "우당탕" 미끄러지며 한 바퀴 구른다 (웃음 포인트, 벌칙 없음).

### 4.5 결과와 보상
- 별이 하나씩 "띵, 띵, 띵" 소리와 함께 병에 차오른다.
- 별 병이 차면 **스티커 한 장**. 스티커북은 30칸 (공룡 15, 탈것 10, 친구 5).
- 별 누적 개수로 **새 부품** 해금 (별 20개마다 1개. 불도저 삽, 로켓, 헬리콥터 프로펠러, 문어 다리 등 우스꽝스러운 것 포함).
- 모은 **공룡 알**은 차고의 둥지로 간다. 알을 5번 톡톡 치면 아기 로봇공룡이 태어나 차고를 돌아다닌다 (2단계에서).

## 5. 보호자 기능

- **보호자 문**: 설정은 "화면 구석 자물쇠를 3초 누르기"로만 열린다 (아이가 우연히 못 들어가게).
- **하루 시간 제한**: 10분 · 20분 · 30분 · 제한 없음. 시간이 되면 판을 끊지 않고, 이번 판이 끝난 뒤
  "로봇공룡이 졸려요. 내일 또 만나!" 하며 공룡이 잠드는 화면으로 끝낸다 (억지로 끊으면 떼를 쓴다).
- **소리**: 음악 · 효과음 · 목소리 안내 따로 켜고 끄기.
- 기록은 이 태블릿 안에만 저장. 인터넷 없이도 된다 (홈 화면에 추가하면 앱처럼).

## 6. 화면·소리 스타일

- 가로 화면 고정 권장. 캔버스에 도형으로 그린다 (N-GUN처럼 이미지 파일 0개).
- 색: 채도 높은 원색 + 두꺼운 어두운 테두리 (그림책 느낌). 배경은 파스텔로 캐릭터가 도드라지게.
- 효과음: 철컥(조립), 뽀용(점프), 쿵(착지), 와장창(부수기), 띵(별). 모두 합성음.
- 음악: 느긋한 행진곡 풍 (N-GUN 시퀀서를 밝은 장조로 재사용).

## 7. 만드는 순서

| 단계 | 내용 | 확인할 것 |
|---|---|---|
| 1 (시제품) | 차고(부품 9개·색 6개) + 정글 1곳 + 스티커 5장 + 목소리 안내 | 아이가 설명 없이 시작해서 끝까지 가는가, 3분 안에 웃는가 |
| 2 | 지도 5곳, 부품 해금, 스티커북 30칸, 사진 찍기 | "한 번 더!"가 나오는가, 어떤 부품을 제일 좋아하는가 |
| 3 | 알 부화·아기 공룡, 보호자 시간 제한, 우스꽝스러운 부품 추가 | 하루 제한을 순순히 받아들이는가 |

1단계만으로 바로 해 볼 수 있게 만들고, 아이 반응을 보고 2단계 방향을 고친다.

## 8. 파일 구조 (계획)

```
dino/
├── index.html
├── style.css
├── PLAN.md          이 문서
└── js/
    ├── data.js      부품·지형·스티커 목록 (내용 추가는 여기만)
    ├── garage.js    조립 화면
    ├── run.js       달리기 규칙 (DOM 없음, node 테스트 가능)
    ├── render.js    그리기
    ├── voice.js     목소리 안내 (speechSynthesis, 없으면 조용히 넘어감)
    ├── audio.js     효과음·음악 (N-GUN 것을 가져와 밝게)
    └── main.js      화면 전환·보호자 설정
```

저장소 첫 화면(`index.html`)은 N-GUN과 로봇공룡 두 개를 고르는 큰 버튼 화면으로 바꾼다.

## 9. 정하면 좋은 것 (보호자에게)

1. 아이가 제일 좋아하는 게 공룡·로봇·자동차 중 무엇인가 (주인공 모양의 비중이 달라진다)
2. 한글을 읽을 수 있는가 (읽을 수 있으면 짧은 단어를 화면에 같이 띄운다)
3. 하루 몇 분 정도를 생각하는가 (기본값을 정한다)
