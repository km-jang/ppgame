# 소리 파일 출처

이 폴더의 `.ogg` 파일은 Kenney(kenney.nl)가 GitHub에 공개한 스타터 키트에서 가져왔다. MIT 라이선스이며 아래 고지를 함께 둔다.
돈이 들지 않고, 게임에 넣어 배포해도 된다 (고지만 유지).

| 파일 | 가져온 곳 |
|---|---|
| jump, land, coin, break, fall | github.com/KenneyNL/Starter-Kit-3D-Platformer (`sounds/`) |
| jump_a, jump_b, jump_c, weapon_change | github.com/KenneyNL/Starter-Kit-FPS (`sounds/`) |
| impact, skid, engine | github.com/KenneyNL/Starter-Kit-Racing (`audio/`) |
| placement-a, placement-c, removal-a | github.com/KenneyNL/Starter-Kit-City-Builder (`sounds/`) |
| tile-match, tile-land | github.com/KenneyNL/Starter-Kit-Match-3 (`sounds/`) |
