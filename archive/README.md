# 보류 (archive)

소유자 결정으로 첫 화면에서 뺀 게임을 지우지 않고 보관하는 곳. 되살릴 때는 폴더를 저장소 맨 위로 다시 옮기고
첫 화면(`index.html`)에 카드를 다시 넣는다.

| 폴더 | 게임 | 보류한 날 | 이유 |
|---|---|---|---|
| `robocar/` | 뚝딱 로봇카 (5~6세용 변신 로봇카) | 2026-09-27 | 소유자: "자동차 폐기, 폴더 구성 폐기나 보류로 이동". 아이용은 뿅뿅 우주선·냠냠 뱀으로 |

- 테스트는 폴더 안 `robocar/tests/`로 옮겼다 (`node archive/robocar/tests/robocar.test.js` · `park.test.js` · `flow.test.js`). 저장소 필수 테스트에서는 뺐다.
- 주소가 `robocar/`에서 `archive/robocar/`로 바뀌어, 예전에 홈 화면에 설치한 로봇카 앱은 새로 받지 못한다.
- 로봇카 미리보기 주소(https://claude.ai/artifact/VjcTry8wHiiamThjBWTnhG)는 마지막 버전 그대로 남아 있다.
