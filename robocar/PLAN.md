# 뚝딱 로봇카 기획서

> 2026-09-24. 대상: 5~6세 남자아이. 기기: 갤럭시탭 (터치, 가로 화면).
> 첫 초안은 "로봇 공룡"이었으나 보호자 답변(좋아하는 것: **로봇 자동차**, 한글: **읽음**, 시간 관리: **타이머**)에 맞춰
> **변신 로봇카**로 바꿨다.

## 1. 한 줄 요약

부품을 끼워 **나만의 변신 로봇카**를 만들고, 도시를 달리며 별을 모아 **스티커**를 받는 게임.
빨간 **변신!** 버튼을 누르면 로봇으로 변해 상자를 부순다. 지는 일은 없다.

## 2. 설계 원칙

1. **짧은 글자 + 목소리.** 한글을 읽으므로 화면에 짧은 말풍선(자막)을 띄우고, 같은 말을 태블릿의 한국어 음성으로 읽어 준다 (파일 없음, 없으면 자막만).
2. **지는 일이 없다.** 게임 오버 없음. 구덩이에 빠지면 "뿅" 하고 건너편으로 튀어나오고, 바위에 부딪히면 저절로 폴짝 넘는다.
3. **버튼은 크게, 개수는 적게.** 달리기 중에는 "화면 누르기(점프)"와 "변신!" 버튼 두 가지뿐.
4. **누르면 무조건 반응.** 차고에서 로봇카를 누르면 빵빵 하고 폴짝 뛴다.
5. **무섭지 않게.** 원색·두꺼운 테두리(그림책 느낌). 악당 대신 바나나를 던지는 장난꾸러기 원숭이 로봇.
6. **보호자가 안심하게.** 광고·결제·외부 링크·데이터 수집 없음. 하루 타이머.

## 3. 흐름

```
[시작] → [차고] 차체·바퀴·장비·색 고르기 → [달리기] 약 1분 → [결과] 별 병·스티커 → [차고/또 달리기]
                                                     ↘ 오늘 시간이 끝나면 [잠자기]
```

## 4. 부품 (시제품 9개 + 색 6개 = 162가지 조합)

| 칸 | 부품 | 달리기에서 |
|---|---|---|
| 차체 | 레이서 | 변신하면 **슝 돌진**: 1.8배 빠르게 달리며 다 부숨 |
| 차체 | 소방차 | 변신하면 **물대포**: 앞의 불을 모두 끄고 별로 바꿈 |
| 차체 | 경찰차 | 변신하면 **사이렌**: 원숭이가 도망가고 주변 별이 빨려 옴 |
| 바퀴 | 보통 바퀴 | 기본 |
| 바퀴 | 몬스터 바퀴 | 1.22배 높이 점프 |
| 바퀴 | 스프링 바퀴 | 공중에서 한 번 더 점프 |
| 장비 | 제트팩 | 공중에서 꾹 누르면 날아오름 (1.3초) |
| 장비 | 날개 | 공중에서 꾹 누르면 천천히 활공 |
| 장비 | 드릴 | 차 모습으로도 상자·바위를 뚫고 지나감 |

어떤 조합이든 끝까지 간다 (테스트로 27가지 부품 조합 전부 확인). 맞는 부품이면 별을 더 받을 뿐이다.

## 5. 달리기 (도시 1코스)

- 저절로 달린다. **화면 아무 데나 누르기** = 점프, **꾹 누르기** = 제트팩·날개.
- **변신!** 버튼: 3.5초 동안 로봇. 쓰고 나면 5초 뒤 다시 반짝이며 흔들린다.
- 코스 조각: 별 길, 공사 구덩이, 나무 상자, 바위, 불, 점프대, 높은 별(장비 보너스), 원숭이 로봇.
- 상자: 로봇이면 와장창 + 별 2~3개, 차로 박으면 쿵 튕기고 별 1개 (막히지 않음).
- 약 1분, 별 110~140개.

## 6. 보상

- 결과 화면에서 별이 병에 차오른다. **별 15개 = 스티커 1장** (시제품 10장).
- 스티커북: 받은 건 색깔, 못 받은 건 회색 그림자 + "?".

## 7. 하루 타이머 (보호자 답변 반영)

- 기본 **하루 20분**. 화면 오른쪽 위 **배터리**가 남은 시간을 보여 준다 (초록 → 노랑 → 빨강 깜빡).
- 2분쯤 남으면 "배터리가 조금 남았어요!" 한 번 알려 준다.
- 0이 되면 **달리던 판은 끝까지** 하고, 결과를 본 뒤 **잠자기 화면**(밤, 로봇카가 코 자며 충전)으로 넘어간다. 억지로 끊지 않는다.
- 날짜가 바뀌면 다시 가득 찬다.
- **보호자 설정**: 오른쪽 위 자물쇠를 **3초 누르기** → 10·20·30분·제한 없음, 오늘 10분 더 주기, 목소리·소리 켜고 끄기, 오늘 논 시간.

## 7.6 갤럭시탭 우선 (2026-09-24, 보호자: 모바일 위주, 갤럭시탭이 메인)

기준 화면: 갤럭시탭 S9·S8 11인치 (CSS 1280×800, 16:10 가로). 보급형 탭 A 계열(893×533 등)과 12.4인치 S+ 계열도 확인.

| 항목 | 내용 |
|---|---|
| 가로 전용 | **기기를 세로로 들었을 때만** "태블릿을 옆으로 눕혀 줘!" 화면 + 목소리, 달리던 판은 자동 멈춤. 방향은 창 모양이 아니라 기기 방향(`screen.orientation`, 예전 iOS는 `window.orientation`)으로 판단 |
| 좁은 가로 창 | (2026-09-24, 소유자: 갤럭시탭에서 가로세로 인식이 안 됨) Claude 앱 옆 창·화면 분할·주소창 때문에 가로로 들었는데도 창이 좁으면, 막지 않고 버튼·패널까지 통째로 줄이고(zoom) 게임 화면은 위아래를 비워 가운데에 둔다. 돌린 직후 크기가 늦게 바뀌는 안드로이드를 위해 방향 바뀜 알림·조금 뒤 다시 재기·매 프레임 크기 확인 |
| 전체 화면 | 첫 "시작" 때 전체 화면 + 가로 고정 시도, 오른쪽 위 전체 화면 버튼 |
| 앱처럼 설치 | 크롬 메뉴 → 홈 화면에 추가 → 주소창 없는 전체 화면·가로 앱 (`manifest.json`, `icon.svg`) |
| 인터넷 없이 | `sw.js`가 게임 파일·글꼴을 태블릿에 저장 (차 안·와이파이 없는 곳) |
| 120Hz 화면 | S 시리즈는 120Hz라 그대로면 두 배로 그림 → 60번만 그려 배터리·발열 절약 |
| 손바닥 무시 | 태블릿을 쥔 손이 화면 가장자리에 닿아도(접촉 면적 70px 초과) 점프하지 않음 |
| 여러 손가락 | 손가락마다 따로 기억해서, 한 손가락을 떼도 다른 손가락이 누르고 있으면 제트팩 유지 |
| 실수로 나가기 방지 | 안드로이드 뒤로 가기 제스처 → 게임이 꺼지지 않고 "잠깐 멈춤" 화면, 홈 버튼으로 나갔다 오면 멈춤 |
| 화면 켜짐 유지 | 달리는 동안 화면이 어두워지지 않음 (Wake Lock) |
| 진동 | 부수기·변신·결승에 짧은 진동 (진동 모터가 있는 기기만, 보호자 설정에서 끄기) |
| 화질 | 보호자 설정: 자동(기본, 느리면 스스로 낮춤) · 선명하게 · 배터리 절약. 메모리 3GB 이하·4코어 이하 기기는 한 단계 낮게 시작 |

## 7.9 두 번째 코스: 공사장 (2026-09-24)

도시를 **한 번 끝까지** 달리면 열린다. 결과 화면에 "새 코스: 공사장!" + 목소리, 코스 고르기 화면에 "새 코스!" 표시.
코스가 하나뿐일 때는 고르는 화면 없이 바로 출발한다 (처음 하는 아이가 헷갈리지 않게).

| 조각 | 규칙 | 비고 |
|---|---|---|
| 고깔 줄 (4개) | 그냥 달려서 쓰러뜨리면 하나에 별 하나, 막히지 않음 | "와르르!" |
| 콘크리트 관 | 방호벽과 같다: 차는 저절로 폴짝, 로봇·드릴은 부숨 | |
| 흙더미 | 점프대와 같다 | |
| 기중기 갈고리 | 높은 별 (제트팩·날개·스프링·몬스터 보너스) | 매달린 빔이 흔들림 |
| 진흙 웅덩이 | 차는 철퍼덕 0.7초 느려짐(벌칙 없음), 점프로 피함, 로봇은 첨벙 통과. **소방 로봇 물대포가 씻어 내면 별 2개** | "철퍼덕!" |
| 구덩이·상자·원숭이 | 도시와 같다 | |

배경: 기중기와 뼈대만 선 건물(먼 층), 비계·초록 안전망·"안전제일" 현수막·컨테이너·현장 사무실(가까운 층), 흙길과 바퀴 자국,
파란 가림막, 조명탑(밤에 켜짐), 흙을 파는 굴착기, 흙 실은 덤프트럭, 모래주머니·철근(전경). 낮·노을·밤 흐름은 도시와 같다.

## 7.10 손맛: 점프·달리기 매끄럽게 (2026-09-24)

소유자 피드백: "점프나 플레이가 매끄럽지 못하다". 한 판을 프레임 단위로 재 보니 원인이 넷이었다.
상자·방호벽에 부딪히면 차가 20~55px **뒤로 순간 이동**(한 판 5번), 박치기·돌진 때 **속도가 한 번에 뚝·팍**(24번),

| 애니메이션 12원칙 | 늘어나고 눌리기 | 뛸 때 위로 쭉 늘어나고, 내릴 때 눌린다 |

그 밖에: 상자에 박으면 순간 이동 대신 뒤로 살짝 밀렸다 다시 가속, 구덩이에서는 벽 안에서 떨어졌다가 포물선을 그리며 건너편에 착지,
높이 뜰수록 화면이 단계 없이 조금씩 멀어짐, 90Hz 화면은 걸러 그리지 않음(120Hz 이상만 60번으로).
수치는 `data.js` `RUN`의 `step·fallMul·apexMul·buffer·coyote·accel·decel·knock·hopAhead·popTime` 한 곳에서 조절한다.
테스트: 주사율별 같은 점프 높이, 점프 기억, 코요테, 한 판 내내 순간 이동 없음, 방호벽 자동 넘기.

**조정 (소유자: "점프가 너무 높고 둥실해")**: 중력 2300 → 2600, 점프 힘 820 → 790, 꼭대기 둥실 0.55배 → 0.85배(거의 없앰),
내려올 때 1.3배 → 1.4배. 점프 높이 146 → 117(약 20% 낮게), 공중 시간 0.57초. 낮아진 점프로도 넘도록 구덩이 폭 130~190 → 110~155,
차가 길어서 바퀴 하나가 걸쳐 있으면 빠지지 않게 가장자리 25px 여유. 테스트: 점프 높이 100~130, 보통 점프로 가장 넓은 구덩이 넘기.

## 7.13 기록 지키기 · 개인 기록 (2026-09-24, 소유자: "개인기록 레코딩 되고 아이템 해금한거 계속 유지되?")

웹 게임의 기록은 태블릿 브라우저 저장소(localStorage)에 있다. 창을 닫거나 태블릿을 껐다 켜도 남지만,
브라우저 "사이트 데이터 삭제", 다른 브라우저·다른 태블릿, 저장 공간 부족 때 브라우저가 스스로 정리하면 사라질 수 있다.
그래서 `js/save.js`가 세 겹으로 지킨다. 서버로 보내는 것은 없다 (돈 0원, 데이터 수집 없음).

| 겹 | 무엇 | 언제 |
|---|---|---|
| 1 | 예비 사본: 기록 전체를 한 덩어리로 localStorage `rc.backup`과 IndexedDB(`robocar-save`) 두 곳에 더 적는다 | 저장할 때(0.5초 모아서), 게임을 열 때, 닫거나 다른 앱으로 갈 때 |
| 2 | 되살리기: 본 기록이 비었거나 깨졌으면 `rc.backup`으로, localStorage가 통째로 비었으면 IndexedDB로 되살리고 한 번 다시 연다 | 게임을 열 때 자동 |
| 3 | 지워지지 않게 요청 `navigator.storage.persist()` | 시작 버튼을 누를 때 (N-GUN도) |
| 4 | 옮기기: 보호자 화면 → 놀이 기록 탭 "기록 지키기"에서 파일·코드로 내보내고 불러오기 | 태블릿을 바꾸거나 브라우저를 지우기 전 |

안전장치: 시작할 때 기록이 하나도 없으면 IndexedDB를 다 볼 때까지 예비 사본을 쓰지 않는다 (새 빈 기록이 좋은 사본을 덮지 않게).
되살리거나 불러온 뒤 다시 열 때까지는 저장을 멈춘다 (게임이 들고 있던 옛 기록으로 덮지 않게).

개인 기록: 코스별 최고 별(`prog.best`, 코스 카드에 "최고 ★ N", 깨면 결과에 "최고 기록" + 목소리), 구한 친구 모두(`prog.rescued`),
가장 큰 공중 보너스(`prog.bestAir`). 보호자 화면 놀이 기록 탭에서 모두 본다. 열린 부품은 모은 별(`prog.total`)로 정해지므로 기록과 함께 지켜진다.

주의: 미리보기(Artifact) 창의 저장소는 미리보기 서비스 사정에 따라 비워질 수 있다. 실제로 쓸 때는 GitHub Pages 주소로 연다.

| D | **물대포 구조대** | 자동 사격·총열 N | 차 지붕에 물대포가 달려 자동으로 쏜다. 적 대신 불난 건물·풍선·진흙 덩어리를 맞히면 불이 꺼지고 친구가 나온다. 물줄기 수가 부품으로 늘어난다(총열 N처럼). 맞아도 지는 일 없음 | 중간 |
| E | **위에서 보는 놀이터 모드** (큰 전환) | 위에서 보는 아레나·웨이브 | 옆으로 달리기 대신 N-GUN처럼 위에서 본 공원을 스틱 하나로 돌아다니며 별 모으기·친구 찾기. 판마다 "미션 3개". 조작이 바뀌어 5~6세에 맞는지 먼저 시험해야 한다 | 큼 |

추천 순서: **A → B** (지금 코드 위에 바로 얹고, 아이가 좋아하는지 놀이 기록으로 바로 보인다). 그다음 반응을 보고 C 또는 D. E는 아이가 달리기 자체에 흥미를 잃었을 때만.
