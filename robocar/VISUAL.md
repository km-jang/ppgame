# 뚝딱 로봇카 · 비주얼 레벨업 설계

> 2026-09-24. 보호자 피드백: "너무 유아틱하다. 시간이 걸려도 공을 들여 비주얼을 올리자."
> 목표: **5~6세가 봐도 "멋있다"** (유아용 그림책 → 애니메이션·레이싱 게임 느낌). 조작의 쉬움과 큰 버튼은 그대로 둔다.

## 무엇이 유아틱했나 (진단)

| 요소 | 이전 | 문제 |
|---|---|---|
| 서체 | 둥근 손글씨체 (Jua) | 그림책·유치원 안내문 느낌 |
| 테두리 | 모든 도형에 두꺼운 검정 4px | 색칠공부 느낌, 입체감 없음 |
| 색 | 파스텔 단색 면 | 광택·재질이 없어 장난감 스티커처럼 보임 |
| 얼굴 | 동그란 왕눈이 | 아기용 캐릭터 인상 |
| 배경 | 한 가지 하늘 + 사탕색 건물 | 깊이·시간·분위기 없음 |
| 인터페이스 | 흰 말풍선 + 두꺼운 테두리 버튼 | 키즈 앱 전형 |
| 보상 | 이모지 스티커 | 게임 속 그림과 따로 놂 |

## 다각도 개선 (7개 축)

### 1. 캐릭터 · 재질 (`js/car.js`)
- **도장**: 위는 빛을 받아 밝고 아래로 갈수록 어두운 그라디언트 + 윗선 흰 하이라이트 → 광택 차체.
- **재질 구분**: 크롬(휠·사다리·드릴), 건메탈(관절·부품), 유리(짙은 남색→하늘색 + 반사 줄).
- **발광**: 전조등·후미등·경광등·눈은 빛 번짐 스프라이트를 덧그려 실제로 빛나 보이게.
- **얼굴**: 왕눈이 → 비스듬한 **LED 눈 + 눈썹** (씩씩한 표정, 깜빡임 유지, 잘 땐 감은 눈).
- **차 디자인**: 레이서(쐐기형 슈퍼카·뒷날개·번호판 07·레이싱 줄), 소방차(셔터문·사다리·반사띠), 경찰차(흰 문·POLICE·별 배지·경광등 막대·푸시 범퍼).
- **바퀴**: 5스포크 크롬 휠 + 차체색 허브, 빠를수록 스포크가 흐려짐. 몬스터는 트레드, 스프링은 코일 쇼바.
- **로봇**: 관절식(엉덩이·무릎·어깨·팔꿈치)으로 다시 설계. 넓은 어깨·두꺼운 팔다리의 **히어로 비율**, 가슴에 차 앞유리와 빛나는 코어(번개·물방울·별), 어깨·종아리에 바퀴, 달릴 때 팔다리가 번갈아 움직이고 앞으로 기울어짐. 드릴 장비는 팔이 드릴로 바뀐다.

### 2. 변신 연출
- 빛줄기 10갈래가 회전하며 퍼지고 육각 에너지 링이 커진다.
- 이전 모습이 늘어나며 사라지고 새 모습이 커지며 나타난다.
- **변신하는 동안 느린 화면**(0.45배) + 카메라 확대(1.12배) + 화면 섬광.

### 3. 무대 · 시간 흐름 (`js/scene.js`)
- 한 판 안에서 **낮 → 노을 → 밤**으로 바뀐다 (진행 36~52%에 노을, 66~82%에 밤).
- 하늘 3단 그라디언트, 해가 지며 주황으로 커지고, 밤엔 별이 반짝이고 초승달.
- 건물 2겹 시차 스크롤: 먼 층은 대기 원근(뿌옇게), 가까운 층은 옥상 물탱크·에어컨·**네온 간판**(밤에 빛남)·1층 가게.
- 창문은 낮엔 하늘빛 반사, 노을엔 일부, 밤엔 대부분 불이 켜진다.
- 가로등(밤에 켜지고 빛 원뿔 + 젖은 도로 반사), 나무, 인도 타일, 연석, 아스팔트 질감, 노란 중앙선.
- 전경(카메라보다 빠르게 지나가는 어두운 풀숲·볼라드) → 깊이감.
- 밤엔 로봇카 **전조등 빛**이 도로를 비춘다.

### 4. 장애물 · 수집품
- 나무 상자(판자·대각 보강·못) / 주황 금속 컨테이너(경고 줄무늬) 번갈아.
- 바위 → **콘크리트 방호벽**(주황·흰 반사 줄무늬, 깜빡이는 경고등).
- 불: 흰 심지→노랑→주황→빨강 그라디언트 불꽃 5개가 일렁이고 연기가 오른다. 끄면 물웅덩이와 김.
- 구덩이: 깊이감 있는 흙 구멍 + 양쪽 공사 바리케이드와 경고등.
- 점프대: 강철 경사판 + 트러스 + 노란 화살표.
- 원숭이 로봇: 금속 몸체, 빨간 LED 눈, 깜빡이는 안테나, 꼬리.
- 별: 입체로 면을 나눈 금별 + 빛 번짐, 모으면 **HUD 별 칸으로 날아간다**.
- 결승: 불빛이 흐르는 기둥 + 체커 배너 게이트.

### 5. 카메라 · 손맛
- 카메라가 차를 부드럽게 따라가고, 빠를 땐 앞을 더 보여 준다. 높이 뜨면 살짝 줌아웃.
- 부수기·박치기·착지·변신 때 화면 흔들림, 부수는 순간 0.06초 **타격 멈춤**.
- 공중에선 차가 속도 방향으로 기울고, 경사로에선 경사를 따라 기운다. 착지 땐 눌렸다 펴진다.
- 빠를 때 **속도선**.

### 6. 인터페이스 (`style.css`)
- 서체: 둥근체 → **Black Han Sans**(굵은 디스플레이) + Noto Sans KR.
- 흰 말풍선 → 어두운 유리 패널 + 네온 윗선 + 주황 포인트 띠.
- 버튼: 비스듬한 레이싱 버튼(주황 그라디언트, 두께감 있는 아래 그림자, 누르면 들어감).
- 로고: 크롬 금속 글자 + 주황 "뚝딱" + TRANSFORM · RACE · COLLECT.
- 변신 버튼: 에너지 코어 + 충전 고리(재사용 대기 = 하늘색이 차오름, 변신 중 = 분홍이 줄어듦, 준비 = 주황으로 맥동).
- 차고: **쇼룸**(어두운 스튜디오, 파랑·주황 스포트라이트, 회전판 네온 링, 바닥 반사) + 능력치 막대(속도·점프·하늘·파워).
- 배터리: 칸이 나뉜 네온 배터리.

### 7. 보상: 스티커 → 수집 카드 (`js/cards.js`)
- 게임 속 로봇카를 그대로 그린 **카드** 10장 (일반 4 · 레어 4 · 전설 2).
- 등급별 테두리 색(철색·보라·금), 빛살·육각 무늬 배경, 등급 별, 전설은 홀로그램 반짝임.
- 결과 화면: 별 3개 평가 + 카드 에너지 셀이 차오르고 카드가 뒤집히며 등장(광택 쓸기).
- 도감: 못 모은 카드는 **검은 실루엣 + ?** (무엇이 나올지 궁금하게).
- 예전 스티커 기록은 같은 id로 이어진다.

## 성능

- 하늘·도로·가장자리 어둡게 효과는 시간대가 조금 바뀔 때만 다시 그리고, 건물 층은 시간대별 타일로 미리 그린다.
- **자동 화질**: 달리는 중 2초 평균이 45fps 아래면 해상도를 한 단계(15%) 낮추고 구름·전경을 생략한다 (최저 0.6배).
- 헤드리스 소프트웨어 렌더링(GPU 없음)에서 태블릿 해상도 기준 한 프레임 약 18ms. 실제 기기는 GPU로 그려서 이보다 빠르다.
