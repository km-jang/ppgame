# 통통 점프 기획서

> 2026-09-27 첫 빌드. 냠냠 뱀과 같은 네온 그림체의 위로 튀어 오르는 게임 (두들 점프 방식).

## 1. 한 줄 요약

눈 두 개 달린 광택 네온 공 로봇이 발판에 닿을 때마다 저절로 통통 튀어 오른다.
아이는 왼쪽·오른쪽만 정해 주면 된다. 얼마나 높이 올라갔는지(m)와 모은 별이 점수.

## 2. 목표와 원칙

| 항목 | 결정 |
|---|---|
| 대상 | 아이들 (쉬움이 기본, 부드럽게 끝남) |
| 기기 | 갤럭시탭 가로(1280×800) 우선, 작은 탭(893×533)·세로 폰·PC도 |
| 기술 | 바닐라 JS + Canvas 2D, 빌드 없음, `file://`로도 실행. 이름공간 `JP` |
| 에셋 | 그림·소리 파일 0개. 도형으로 그리고 소리는 WebAudio 합성 |
| 외부 | 구글 글꼴(주아·Rajdhani)만 |
| 저장 | 기록 장부 `jump.rec`, 쉬움/보통 `jump.easy`, 음소거 `jump.muted` (이 기기 안에만) |
| 규칙 | `js/world.js`는 DOM 없음. 1/120초 고정 칸 물리라 60·90·120Hz 화면에서 같은 결과 (`tests/jump.test.js`) |

## 3. 화면 배치

| 화면 | 놀이 기둥 |
|---|---|
| 가로 (탭) | 가운데 세로 기둥, 폭 = 화면 높이 × 0.75 (1280×800이면 600×800, 893×533이면 400×533). 양옆은 우주 배경, 오른쪽에 점수판, 양옆 아래쪽에 큰 화살표 |
| 가로인데 옆자리가 170px보다 좁을 때 | 위 HUD 줄 아래에 기둥 |
| 세로 (폰) | 위 HUD 줄 아래 가로 전체 |

- 기둥 가로 폭은 늘 400점. 화면에 맞춰 늘려 그린다. 세로로 보이는 높이는 화면 비율에 따라 다르다.
- 카메라는 올라가기만 한다. 10m마다 눈금, 내 최고 높이에 금색 점선.

## 4. 조작

| 기기 | 방법 |
|---|---|
| 터치 | 화면 왼쪽 절반을 누르고 있으면 왼쪽, 오른쪽 절반이면 오른쪽. 누른 채 반대쪽으로 옮기면 방향도 바뀜. 누른 쪽 화살표가 밝아진다 |
| 키보드 | ← → 또는 A D. `P` 일시정지, `M` 소리, `Enter` 시작 |

- 기둥 한쪽 끝으로 나가면 반대쪽에서 들어온다.
- 손바닥(닿은 면 70px 넘음)은 무시, 여러 손가락이면 마지막에 누른 손가락.

## 5. 발판 · 아이템 · 위험 (수치는 `js/data.js`)

| 종류 | 모양 | 하는 일 |
|---|---|---|
| 보통 발판 | 하늘색 광택 막대 | 밟으면 4m 튄다 |
| 움직이는 발판 | 보라색, 양 끝 화살표 | 옆으로 오간다 |
| 부서지는 발판 | 주황색, 금 간 자국 | 한 번 튀면 두 조각으로 부서져 떨어진다 |
| 스프링 | 초록 발판 + 용수철 | 아주 높이 (11m) "통!" |
| 구름 발판 | 하얀 뭉게구름 | 2.4초 보였다 1.5초 사라지기를 되풀이. 사라진 동안은 빠진다 (곁 발판으로만 나옴) |
| 별 | 노란 네 갈래 별 | +10점 |
| 로켓 | 주황 동그라미 | 2.2초 쭉 날아오른다. 그동안 가시 폭탄도 괜찮다 |
| 방패 방울 | 하늘색 방울 | 한 번 지켜 준다 (가시 폭탄 또는 떨어짐) |
| 가시 폭탄 (보통) | 빨간 가시 + 노랑·검정 줄무늬, "위험!" 이름표 | 닿으면 끝 |

- 아이템은 나타날 때 3초 동안 이름표를 단다. 가시 폭탄은 처음 보일 때와 가까이 갔을 때 "위험!".
- 높이에 따라 어려워진다 (400m에서 가장 어려움): 발판 간격이 넓어지고 움직이는·부서지는 발판이 늘어난다.
- 발판 간격은 언제나 한 번 튀는 높이보다 작다. 가시 폭탄은 발판에서 튀어 오르는 길과 두 발판 사이 길목에는 놓지 않는다.

## 6. 쉬움과 보통

| | 쉬움 (기본) | 보통 |
|---|---|---|
| 발판 | 넓고(108점) 촘촘 | 84점 |
| 가시 폭탄 | 없음 | 30m부터, 높을수록 많이 |
| 떨어지면 | 구조 구름이 받아 던져 올림, 3번 (HUD와 기둥 바닥에 구름 3개) | 끝. 기둥 바닥에 빨간 위험 띠 |
| 끝 화면 | "잘했어요!" 노란 글씨, 부드러운 소리 | "아래로 떨어졌다" 빨간 글씨 |

## 7. 점수 · 기록 · 메달

- 점수 = 가장 높이 올라간 m + 별 × 10.
- 콤보: 이어서 더 높은 발판을 밟을 때마다 오르고, 튀는 소리가 반음씩 높아진다.
- 기록 장부: 최고 높이·점수·한 판 최고 별, 모두 한 판·모은 별·오른 높이.
- 메달 12개 (동 5 · 은 5 · 금 2): 구름 위로(50m), 하늘 150, 우주 400, 용감한 100(보통 100m), 별 20, 별 60, 통통 스프링(5번), 로켓 발사, 방울 덕분에, 계단 10, 단골(10판), 별 500(모두 합쳐).

## 8. 연출

- 착지하면 찌그러지고 오를 때 늘어난다. 별·스프링에 불꽃, 부서질 때 살짝 흔들림.
- 발광은 미리 그린 스프라이트, 발판·몸통도 미리 그려 찍기만 한다. 입자 160개 상한.
- 움직임 줄이기 설정이면 흔들림·번쩍임·찌그러짐·반짝임을 끈다.
- 해상도 상한 약 220만 픽셀, 100Hz가 넘는 화면은 한 번 걸러 그린다 (물리는 매번).

## 9. 시험 손잡이 (`JP.debug`)

`world` `mode` `rec` `easy` `demo` `view` `pad`, `setEasy(on)` `newGame(seed, {easy})` `pause()` `resume()` `toTitle()` `openMedals()` `autopilot(on)`.
자동 운전 봇(`JP.World.botDir`)은 닿을 수 있는 가장 높은 발판을 골라 가고 가시 폭탄을 피한다. 시작 화면 뒤 시연도 이 봇이 한다.
