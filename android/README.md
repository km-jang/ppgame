# 뿅뿅 놀이터 앱 (안드로이드 APK)

네 게임(뿅뿅 우주선·냠냠 뱀·통통 점프·슝슝 우주 달리기)과 놀이 본부를 **태블릿에 까는 앱 하나**로 묶은 것이다.
게임 파일이 앱 안에 들어 있어서 인터넷이 없어도 열리고, 주소창·상태 줄 없이 화면 전체로 논다.
플레이 스토어에는 올리지 않는다 (돈이 들지 않게, 가족만 쓰는 앱). 만들기는 GitHub가 무료로 해 준다.

- 앱 이름: 뿅뿅 놀이터 (바꾸려면 `app/src/main/res/values/strings.xml`의 `app_name` 한 줄)
- 가로 화면 고정 (태블릿을 뒤집으면 따라 돈다), 노는 동안 화면이 꺼지지 않는다
- 글꼴(주아)은 인터넷이 될 때 받아 온다. 인터넷이 없으면 기본 글꼴로 보인다

## 태블릿에 설치하기 (처음 한 번)

1. 갤럭시탭에서 **Chrome**(또는 삼성 인터넷)을 열고 이 주소로 간다:
   https://github.com/km-jang/n-gun/releases/tag/apk-latest
2. 아래쪽 **Assets**에서 **ppyong-noriteo.apk**를 누른다. "그래도 다운로드" 같은 안내가 나오면 **다운로드**를 누른다.
3. 다 받아지면 화면 위 알림의 **열기**를 누른다. (알림을 놓쳤으면 **내 파일** 앱 → **다운로드** → **ppyong-noriteo.apk**)
4. "보안을 위해 휴대전화에서 이 출처의 알 수 없는 앱을 설치할 수 없습니다" 같은 창이 나오면 **설정**을 누르고
   **이 출처 허용**(또는 "출처를 알 수 없는 앱 설치 허용")을 켠다. 그리고 뒤로 가기를 누른다.
5. **설치**를 누른다. "Play 프로텍트" 창이 나오면 **무시하고 설치** (또는 **설치**)를 누른다.
6. 홈 화면(또는 앱 목록)에 **뿅뿅 놀이터** 아이콘이 생긴다.

설치가 끝나면 4번에서 켠 허용은 다시 꺼 두어도 된다 (설정 → 애플리케이션 → Chrome(또는 내 파일) → 출처를 알 수 없는 앱 설치).

## 새 버전으로 바꾸기

게임이 main에 합쳐지면 GitHub가 몇 분 뒤 새 APK를 같은 주소(위 1번)에 자동으로 올린다.
태블릿에서 설치하기 1~5번을 똑같이 하면 **덮어 설치**된다. 앱을 지우지 말 것: 지우면 그 앱의 기록도 같이 지워진다.
덮어 설치하면 기록(별코인·메달·스티커·최고 기록)이 그대로 남는다. 늘 같은 서명 열쇠로 만들기 때문이다 (아래 "처음 한 번만: 서명 열쇠 등록").

"앱이 설치되지 않았습니다" 또는 "기존 패키지와 서명이 충돌합니다"가 나오면, 서명 열쇠 등록 전에 만든 APK가 깔려 있는 것이다.
이때만 기록을 먼저 내보내고(아래), 옛 앱을 지운 뒤 새로 설치하고, 기록을 불러온다.

## 기록은 브라우저와 따로다

앱 안 기록과 Chrome에서 놀던 기록(https://km-jang.github.io/n-gun/)은 **서로 다른 곳에 저장**된다.
브라우저에서 모은 기록을 앱으로 옮기려면:

1. Chrome으로 게임 첫 화면을 열고 **보호자 화면** → **기록 내보내기**를 누른다 (파일로 받거나 코드를 복사).
2. 앱을 열고 **보호자 화면** → **기록 불러오기**에서 그 파일이나 코드를 넣는다.

앱에서 기록을 파일로 내보내면 태블릿의 **다운로드** 폴더(내 파일 → 다운로드)에 저장되고
"다운로드 폴더에 저장했어요"라고 잠깐 나온다.

## 처음 한 번만: 서명 열쇠 등록 (컴퓨터에서)

서명 열쇠는 "이 앱은 같은 집에서 만든 것"이라는 도장이다. 한 번 등록해 두면 모든 새 APK가 같은 도장을 받아 덮어 설치가 된다.
등록할 값 두 개(이름과 값)는 AI가 따로 전해 준 파일에 있다. **이 값은 저장소·채팅·메일 어디에도 붙이지 말 것.**

1. 컴퓨터 브라우저로 https://github.com/km-jang/n-gun 을 연다.
2. 위쪽 메뉴의 **Settings**(톱니바퀴)를 누른다.
3. 왼쪽 메뉴에서 **Secrets and variables** → **Actions**를 누른다.
4. 초록색 **New repository secret** 버튼을 누른다.
5. **Name** 칸에 `ANDROID_KEYSTORE_B64`, **Secret** 칸에 파일의 긴 글자 한 줄을 통째로 붙여 넣고 **Add secret**을 누른다.
6. 다시 **New repository secret**을 누른다.
7. **Name** 칸에 `ANDROID_KEYSTORE_PASS`, **Secret** 칸에 비밀번호 한 줄을 붙여 넣고 **Add secret**을 누른다.
8. 목록에 두 이름이 보이면 끝. 열쇠 파일은 컴퓨터 안전한 곳(USB 등)에도 한 부 보관해 둔다. 잃어버리면 다음 설치 때 기록을 옮겨야 한다.

등록 전에 만든 APK는 임시 열쇠로 서명되어 있고, Actions 실행 화면에 노란 "서명 열쇠 없음" 경고가 뜬다.

## 만드는 과정 (참고, 손댈 일 없음)

- `.github/workflows/apk.yml`: main이나 작업 브랜치에 코드가 올라가면 GitHub Actions가 돈다.
  웹 파일(`index.html`, `common/`, `game/`, `snake/`, `jump/`, `runner/`, `.md` 제외)을 `app/src/main/assets/www/`에 복사하고
  APK를 만든다. main이면 Releases의 `apk-latest`에 `ppyong-noriteo.apk`를 바꿔 올리고, 작업 브랜치면 그 실행 화면의 **Artifacts**에만 올린다.
  Actions 화면에서 **Run workflow**로 직접 돌릴 수도 있다.
- 복사한 웹 파일은 저장소에 넣지 않는다 (`android/.gitignore`). 원본은 늘 저장소 최상위 파일이다.
- 버전 번호는 Actions 실행 번호를 쓴다 (`1.<번호>`). 새로 만들수록 커져서 덮어 설치가 된다.
- 도구: Android Gradle Plugin 8.5.2 · Gradle 8.7 · JDK 17 · compileSdk/targetSdk 34 · minSdk 24(안드로이드 7) · 자바, 라이브러리는 `androidx.webkit` 하나.

### 앱 속 구조 (`app/src/main/java/io/github/kmjang/ngun/MainActivity.java`)

- 화면은 WebView 하나. 주소는 `https://appassets.androidplatform.net/assets/www/index.html` (WebViewAssetLoader).
  진짜 https 주소처럼 보이므로 상대 링크(`game/index.html`, `../index.html`)와 localStorage가 웹과 똑같이 동작한다.
- 서비스 워커(`sw.js`): 앱에서는 필요 없어서 `sw.js` 요청에 404를 돌려 등록이 조용히 실패하게 했다 (웹 코드는 `.catch`로 받는다).
  `sw.js` 파일은 복사되지만 쓰이지 않는다.
- 앱 밖 주소로는 WebView가 떠나지 않는다. 사용자가 누른 바깥 링크만 인터넷 앱으로 열고, 나머지는 막는다. 구글 글꼴 같은 부품은 그대로 받는다.
- 다른 앱으로 가면 `onPause`에서 WebView를 멈춰 소리·타이머가 멈춘다 (웹 쪽도 visibilitychange로 소리를 멈춘다).
- 길게 눌러도 글자 선택·메뉴가 뜨지 않는다. 진동은 `navigator.vibrate`로 된다 (VIBRATE 권한, 묻는 창 없음).
- 권한은 인터넷(글꼴)·진동 둘뿐. 저장은 다운로드 폴더에 MediaStore로 써서 따로 권한을 묻지 않는다.

### 웹 코드가 쓸 수 있는 앱 창구

| 이름 | 하는 일 |
|---|---|
| `window.AndroidApp.isApp()` | 앱 안이면 `true`. 브라우저에는 `window.AndroidApp` 자체가 없다 |
| `window.AndroidApp.saveText(파일이름, 글)` | 다운로드 폴더에 글 파일로 저장하고 알림을 띄운다. 성공하면 `true`. 안드로이드 9 이하는 앱 폴더(`Android/data/io.github.kmjang.ngun/files/Download`)에 저장 |
| `window.AndroidBack()` (웹이 만들면) | 뒤로 가기 버튼을 누르면 앱이 먼저 이 함수를 부른다. `true`를 돌려주면 웹이 처리한 것으로 보고 앱은 아무것도 안 한다 (예: 게임 중이면 멈춤 화면 열기) |

뒤로 가기 순서: `window.AndroidBack()`이 `true`면 끝 → 이전 화면이 있으면 그리로 → 게임 화면이면 첫 화면으로 → 첫 화면이면 "놀이를 끝낼까요?" (끝내기 / 계속 놀기).

`<a download>`로 Blob을 내려받게 하는 옛 방식도 앱이 내용을 읽어 `saveText`로 저장해 준다 (파일 이름은 `ppyong-record-<시각>.json`). 되도록 `saveText`를 직접 쓸 것.

### 아이콘

`app/src/main/res/mipmap-*/`의 PNG. 뿅뿅 우주선(파란 공과 노란 총열)·냠냠 뱀(초록 물결)·통통 점프(분홍 공)·별을 한 장에 담았다.
헤드리스 크로미움으로 SVG를 그려 만들었다 (크기: 48·72·96·144·192, 적응형 아이콘 앞·뒤 판 108dp).
