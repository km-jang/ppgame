# N-GUN 기획서

> 2026-09-24 재기획. 이전 작업물(방치형 클리커 "sudo make AGI")은 전부 폐기했다.
> 필요하면 git 기록(커밋 `7debd73` 이전)에서 꺼내 볼 수 있다.

## 1. 한 줄 요약

총열이 N개로 늘어나는 총을 들고, 몰려오는 적을 웨이브 단위로 버티는
**아레나 생존 슈팅 게임**. 웨이브를 넘길 때마다 카드 3장 중 1장을 골라 총을 키운다.

## 2. 목표와 원칙

| 항목 | 결정 |
|---|---|
| 플랫폼 | 브라우저 (PC·모바일 모두). 설치 없음 |
| 기술 | 바닐라 HTML/CSS/JS + Canvas 2D. 외부 라이브러리·빌드 도구 없음 |
| 파일 열기 | `game/index.html` 더블클릭으로도 실행 (ES 모듈 대신 일반 스크립트 사용) |
| 에셋 | 이미지·사운드 파일 0개. 도형으로 그리고 효과음은 WebAudio로 합성 |
| 한 판 길이 | 5~15분. 짧게 죽고 바로 다시 하는 구조 |
| 저장 | 난이도별 기록·평생 합계·메달·소리 설정만 브라우저에 저장 (5.9) |

## 3. 핵심 재미

1. **N = 총열 수.** 제목이 곧 성장 축이다. 총열 카드를 고를 때마다 부채꼴 탄막이 넓어진다.
2. **선택의 긴장.** 카드 3장은 서로 다른 성장 방향(화력·생존·기동)을 제시한다.
3. **회피 한 방.** 대시(무적 0.25초)로 탄막과 적 사이를 빠져나가는 손맛.
4. **5웨이브마다 보스.** 링 탄막·조준 사격·졸개 소환으로 빌드를 시험한다.

## 4. 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽 드래그 (가상 스틱) |
| 조준 | 마우스 (F로 자동 조준 전환) | 화면 오른쪽 드래그. 손을 떼면 자동 조준 |
| 사격 | 자동 | 자동 |
| 대시 | Space / Shift | 오른쪽 아래 대시 버튼 |
| 필살기 | Q / E | 대시 버튼 위 N BURST 버튼 (게이지가 가득 찼을 때) |
| 카드 선택 | 클릭 또는 1·2·3 | 탭 |
| 일시정지 | P / Esc | 왼쪽 위 ⏸ |
| 음소거 | M | 왼쪽 위 🔊 |

## 5. 시스템

### 5.1 플레이어
- 체력 5칸, 피격 후 무적 1초, 피격 시 주변 적 탄환 제거(억울한 연속 피격 방지)
- 대시: 0.18초, 이동속도 3.2배, 쿨다운 1.2초

### 5.2 총 (기본값)
| 능력치 | 기본 |
|---|---|
| 총열 N | 1 |
| 연사 | 초당 5발 (총열마다) |
| 위력 | 1 |
| 탄속 | 520 |
| 치명타 | 5%, 2.5배 |

총열이 늘면 부채꼴 각도가 넓어진다 (총열 사이 0.12rad, 최대 약 160도).

### 5.3 적
| 종류 | 등장 | 특징 |
|---|---|---|
| 졸개 | 1웨이브~ | 곧장 추격 |
| 돌격병 | 2웨이브~ | 작고 빠름 |
| 사수 | 3웨이브~ | 거리를 유지하며 탄 발사 |
| 중장갑 | 4웨이브~ | 느리고 단단함 |
| 분열체 | 6웨이브~ | 죽으면 새끼 2마리로 갈라짐 |
| 보스 | 5의 배수 웨이브 | 링 탄막·3연 조준 사격·졸개 소환, 체력 50% 이하에서 격노 |

- 적은 경고 원(0.6초)을 먼저 보여준 뒤 나타난다. 플레이어 180px 안에는 생성하지 않는다.
- 웨이브가 오를수록 체력 +15%씩, 속도 최대 +40%, 동시 생성 수 증가.

### 5.4 카드 (웨이브 클리어 보상)
| 카드 | 효과 | 최대 |
|---|---|---|
| 총열 추가 | N +1 | 11 |
| 연사 | 연사 +20% | 8 |
| 위력 | 위력 ×1.25 | 10 |
| 고속탄 | 탄속 +20%, 사거리 +15% | 5 |
| 관통탄 | 적 1마리 더 관통 | 5 |
| 도탄 | 벽에서 1번 더 튕김 | 4 |
| 대구경 | 탄 크기 +30%, 위력 +10% | 4 |
| 급소 조준 | 치명타 확률 +8% | 5 |
| 경량화 | 이동속도 +12% | 4 |
| 강화 외골격 | 최대 체력 +1, 전부 회복 | 5 |
| 추진기 | 대시 쿨다운 -25% | 3 |
| 궤도 드론 | 주위를 도는 드론 +1 | 4 |
| 흡혈 | 처치 시 4% 확률로 체력 +1 | 3 |
| 충격파 | 대시가 끝날 때 주변 폭발 | 3 |
| 응급 수리 | 체력 2 회복 (다른 카드가 없을 때만) | 무제한 |

카드 무게: 총열 추가는 드물게(가중치 2), 나머지는 3~5.

### 5.4.1 필살기 N-버스트 (2026-09-26, 소유자: "공격 포인트가 어느 정도 쌓이면 쓸 수 있게")
| 항목 | 내용 |
|---|---|
| 게이지 | 적에게 준 피해로 찬다. 단위는 "적 기본 체력만큼의 피해"라서 웨이브·난이도로 적이 단단해져도 한 마리당 차는 양이 같다 (졸개 1마리 = 3, 가득 = 90) |
| 보스 | 보스에게 준 피해는 35%만 찬다 (보스전에 연달아 쓰지 않게) |
| 발동 | 가득 차면 대시 버튼 위 금빛 **N BURST** 버튼 (PC: `Q` 또는 `E`) |
| 효과 | 나를 중심으로 금빛 충격파가 화면 끝까지 퍼진다(초당 1500px). 닿은 적마다 한 번 큰 피해 + 밀어내기, 닿은 적 탄은 지운다. 발동 순간 0.9초 무적·0.14초 화면 멈춤·흰 번쩍·흔들림·진동 |
| 피해 | 지금 총의 4초치 화력(총열 × 연사 × 위력, 최소 위력 × 20) × 웨이브 체력 배율. 일반 적은 대부분 쓸려 나가고 보스는 40%만 받아 체력의 5분의 1 안팎 |
| 모양 | 충격파에 총열 N × 3개의 빛줄기. 가득 차면 내 기체에 금빛 기운이 맥박치고, HUD 대시 게이지 아래에 N-BURST 게이지 |
| 필살기 피해는 게이지를 채우지 않는다 | 연쇄 발동 방지 |

실측(봇, 시드 5개): 첫 발동 3웨이브 무렵, 뒤로 갈수록 웨이브마다 한 번쯤. 수치는 `data.js` `ULT`.

### 5.5 점수
적 처치 점수 × (1 + 보스 처치 수 × 0.5) × 콤보 배율(5.9). 보스 처치 +1000. 기록은 5.9.

### 5.6 난이도 (시작 화면에서 선택, 기록도 난이도별로 따로)
| 항목 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 내 체력 | 8 | 5 | 4 |
| 적 체력 | ×0.6 | ×1 | ×1.5 |
| 적 속도 | ×0.8 | ×1 | ×1.2 |
| 적 수 | ×0.75 | ×1 | ×1.3 |
| 적 탄 속도·연사 | ×0.75·×0.7 | ×1 | ×1.2·×1.35 |
| 점수 | ×0.6 | ×1 | ×1.6 |

수치는 `data.js`의 `DIFFICULTY`. 자동 봇 측정(시드 10개): 쉬움 평균 20웨이브, 보통·어려움은 첫 보스(5웨이브) 부근.

### 5.7 소리 (파일 0개, 전부 WebAudio 합성)
- 총소리: 대역 잡음 "탕" + 저역 잡음 몸통 + 저음 펀치 + 금속성 딸깍. 총열 N이 늘수록 두껍고 낮아진다
- 폭발·보스 격파: 필터를 쓸어내리는 잡음 + 저음
- 배경음악: A단조 4마디 루프(Am-F-C-G) 16스텝 시퀀서. 시작 화면 100BPM(베이스·하이햇만) → 게임 128BPM(킥·스네어·아르페지오) → 보스전 146BPM(진행 변경 + 리드 멜로디)
- 일시정지 때 음악을 줄이고, 게임 오버 때 멈춘다. 음악·효과음 따로 켜고 끄기, 전체 음소거(M)
- 피격 시 진동(지원하는 기기만)

### 5.8 모바일 우선 (2026-09-24, 소유자 지시: PC 기반이 아니어도 됨)
PC 조작은 남겨 두되 화면·성능은 폰·태블릿(갤럭시탭) 기준으로 맞춘다.
- 성능: 해상도 상한 약 220만 픽셀(태블릿 2560×1600을 그대로 그리지 않음), 배경 격자·발광을 미리 그려 이미지로 찍기(shadowBlur 제거), 불투명 캔버스, 일시정지·카드 화면에선 다시 그리지 않음
- 조작: 대시 버튼 88px(태블릿 104px) + 재사용 대기 원형 게이지, 누를 때 짧은 진동, 게임 시작 5초간 "드래그: 이동/조준" 안내, 카드 오터치 방지 0.6초
- 이동 조작 개선 (소유자 피드백: 이동이 부자연스러움): 왼쪽 아래에 항상 보이는 실물 느낌 엄지 스틱(움푹한 받침 + 볼록한 머리 + 방향 눈금), 스틱 근처를 누르면 스틱 자리에서 시작하고 멀리 누르면 그 자리로 따라옴, 반경 밖으로 끌면 받침이 손가락을 따라와 방향 전환이 즉각적, 반응 곡선(가운데 12% 무시·70%만 밀어도 최고 속도), 속도 즉시 전환 대신 약 0.1초 가속·감속, 오른쪽 조준 스틱도 같은 모양(분홍), 대시는 눌리면 쑥 들어가는 오락실 버튼
- 화면: 터치 버튼 최소 44px, HUD 1.15~1.35배, 가로로 눕힌 폰은 시작 화면 두 칸 배치, 당겨서 새로고침·길게 눌러 메뉴 차단
- 기기 기능: 게임 중 화면 꺼짐 방지(Wake Lock), 전체 화면 버튼(주소창 숨김), 홈 화면에 추가하면 앱처럼 전체 화면 실행(manifest.json)

| 총이 커진 뒤 N-버스트 한 방에 보스가 통째로 사라짐 (설계는 "보스 체력의 5분의 1 안팎") | 필살기 피해는 총·웨이브에 비례해 커지는데 보스 체력은 보스 횟수로만 는다. 봇 실측: 상한 전 쉬움 보스전 필살기의 절반 이상이 한 방 | 한 번에 보스 최대 체력의 25%까지만 (`ULT.bossCap`) | 점검: 총이 커져도 필살기 한 번에 보스 체력의 bossCap까지만 깎는다 |
| 시작 화면을 오래 켜 두면 뒤의 시연 판 적이 계속 늘어남 | 시연 판이 끝없이 웨이브를 올렸다 | 8웨이브를 넘기면 처음부터 (`main.js`) | 화면 쪽이라 규칙 테스트 없음 |
| 망가진 저장본(숫자 대신 글자 등)이면 기록 저장에서 멈출 수 있음 | 저장소에서 읽은 값을 그대로 썼다 | `records.js`가 모양을 검사하고 이상한 값은 0 | 기록: 옛 최고 기록(ngun.best2, ngun.best)을 이어받고 망가진 저장본에도 안 멈춘다 |
| 움직임 줄이기 설정에서도 화면 흔들림·번쩍임 | 캔버스 연출은 설정을 안 봤다 | 흔들림·배너 미끄러짐·콤보 튀어 오름을 빼고 흰 번쩍임을 약하게, 새 CSS 연출도 끔 | 화면 쪽 |

점검했지만 문제 없던 것: 일시정지·카드·게임 오버 중 필살기 발동과 게이지 충전(막혀 있음), 카드를 고르거나 다시 시작할 때 눌러 둔 Q(입력을 비움), 충격파 중 생긴 분열체 새끼(같은 충격파에 쓸림, 테스트 추가), 웨이브 사이 게이지 유지(설계대로), 소리 끔 상태의 새 소리, 계속 커지는 배열(입자 700개·글자 40개 상한, 나머지는 매 프레임 정리), 작은 탭(893×533)·가로 폰(844×390)의 버튼 겹침.

- 보스 상한 뒤 실측(피하는 봇, 시드 6개): N-버스트 한 번에 깎인 보스 체력(충격파가 도는 동안의 총 피해 포함) 중앙값 쉬움 26% · 보통 13%. 상한 전에는 쉬움 보스전의 절반 이상이 한 방이었다.
- 필살기는 설계("뒤로 갈수록 웨이브마다 한 번쯤") 그대로 차고, 살아남는 웨이브를 두 배 가까이 늘린다. 비상 버튼이 주인공인 셈이라 게이지 수치는 그대로 두고, 보스를 한 방에 지우는 것만 막았다 (위 표).
- 총열 N은 드물다: 20웨이브쯤에 평균 N 2~3. 총열 카드 가중치 2는 5.4의 결정이라 그대로 두고, 메달 문턱을 N 3·5·8로 맞췄다.

#### 연속 처치 콤보 (`data.js` `COMBO`)
- 앞 처치 뒤 1.6초 안에 또 잡으면 이어진다. 맞으면 끊긴다.
- 점수 배율 = 1 + 5콤보마다 0.1 (최대 ×2, 50콤보). 3콤보부터 오른쪽 위 점수 아래에 "x17 COMBO"가 잡을 때마다 튀어 오르고, 끊기기까지 남은 시간 막대와 "SCORE x1.3". 색은 청록 → 노랑(10) → 주황(25) → 분홍(50).
- 10·25·50·100콤보를 넘길 때 짧은 소리. N-버스트 한 방에 여러 마리를 잡으면 콤보가 크게 뛴다 (둘이 서로 살려 준다).

## 7. 코드 구조

```
game/
├── index.html      화면 뼈대 + 오버레이
├── style.css       네온 테마, 모바일 대응

    ├── records.js  기록·메달 (DOM 없음, 저장은 NG.store로만)
    ├── render.js   캔버스 그리기
    ├── input.js    키보드·마우스·터치 스틱

tests/
```

규칙(world.js)과 그리기(render.js)를 나눠서, 게임 규칙은 브라우저 없이 `node tests/sim.test.js`로 검증한다.
