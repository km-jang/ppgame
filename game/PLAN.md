# N-GUN 기획서

> 2026-09-24 재기획. 이전 작업물(방치형 클리커 "sudo make AGI")은 전부 폐기했다.
> 필요하면 git 기록(커밋 `7debd73` 이전)에서 꺼내 볼 수 있다.

## 1. 한 줄 요약

총열이 N개로 늘어나는 총을 들고, 몰려오는 적을 웨이브 단위로 버티는
**아레나 생존 슈팅 게임**. 웨이브를 넘길 때마다 카드 3장 중 1장을 골라 총을 키운다.

## 2. 목표와 원칙

| 항목 | 결정 |
|---|---|
| 플랫폼 | 브라우저 (PC·모바일 모두). 설치 없음 |
| 기술 | 바닐라 HTML/CSS/JS + Canvas 2D. 외부 라이브러리·빌드 도구 없음 |
| 파일 열기 | `game/index.html` 더블클릭으로도 실행 (ES 모듈 대신 일반 스크립트 사용) |
| 에셋 | 이미지·사운드 파일 0개. 도형으로 그리고 효과음은 WebAudio로 합성 |
| 한 판 길이 | 5~15분. 짧게 죽고 바로 다시 하는 구조 |
| 저장 | 난이도별 기록·평생 합계·메달·소리 설정(5.9), 코인·기체·강화·시작 아이템·미션(5.10)만 브라우저에 저장 |

## 3. 핵심 재미

1. **N = 총열 수.** 제목이 곧 성장 축이다. 총열 카드를 고를 때마다 부채꼴 탄막이 넓어진다.
2. **선택의 긴장.** 카드 3장은 서로 다른 성장 방향(화력·생존·기동)을 제시한다.
3. **회피 한 방.** 대시(무적 0.25초)로 탄막과 적 사이를 빠져나가는 손맛.
4. **5웨이브마다 보스.** 링 탄막·조준 사격·졸개 소환으로 빌드를 시험한다.

## 5. 시스템

### 5.1 플레이어
- 체력 5칸, 피격 후 무적 1초, 피격 시 주변 적 탄환 제거(억울한 연속 피격 방지)
- 대시: 0.18초, 이동속도 3.2배, 쿨다운 1.2초

### 5.2 총 (기본값)
| 능력치 | 기본 |
|---|---|
| 총열 N | 1 |
| 연사 | 초당 5발 (총열마다) |
| 위력 | 1 |
| 탄속 | 520 |
| 치명타 | 5%, 2.5배 |

총열이 늘면 부채꼴 각도가 넓어진다 (총열 사이 0.12rad, 최대 약 160도).

### 5.3 적
| 종류 | 등장 | 특징 |
|---|---|---|
| 졸개 | 1웨이브~ | 곧장 추격 |
| 돌격병 | 2웨이브~ | 작고 빠름 |
| 사수 | 3웨이브~ | 거리를 유지하며 탄 발사. 난이도만큼 내가 가는 쪽을 앞질러 쏜다 (5.11) |
| 돌진이 | 3웨이브~ | 주황 화살촉. 가까우면 멈춰서 주황 점선 예고(0.75초, 방향은 예고 시작 때 굳음) 뒤 쏜살같이 돌진 (5.11) |
| 중장갑 | 4웨이브~ | 느리고 단단함 |
| 분열체 | 6웨이브~ | 죽으면 새끼 2마리로 갈라짐 |
| 보스 | 5의 배수 웨이브 | 링 탄막·3연 조준 사격·졸개 소환, 체력 50% 이하에서 격노 |

- 적은 경고 원(0.6초)을 먼저 보여준 뒤 나타난다. 플레이어 180px 안에는 생성하지 않는다.
- 웨이브가 오를수록 체력 +15%씩, 속도 최대 +40%, 동시 생성 수 증가.

### 5.4.1 필살기 N-버스트 (2026-09-26, 소유자: "공격 포인트가 어느 정도 쌓이면 쓸 수 있게")
| 항목 | 내용 |
|---|---|
| 게이지 | 적에게 준 피해로 찬다. 단위는 "적 기본 체력만큼의 피해"라서 웨이브·난이도로 적이 단단해져도 한 마리당 차는 양이 같다 (졸개 1마리 = 3, 가득 = 90) |
| 보스 | 보스에게 준 피해는 35%만 찬다 (보스전에 연달아 쓰지 않게) |
| 발동 | 가득 차면 대시 버튼 위 금빛 **N BURST** 버튼 (PC: `Q` 또는 `E`) |
| 효과 | 나를 중심으로 금빛 충격파가 화면 끝까지 퍼진다(초당 1500px). 닿은 적마다 한 번 큰 피해 + 밀어내기, 닿은 적 탄은 지운다. 발동 순간 0.9초 무적·0.14초 화면 멈춤·흰 번쩍·흔들림·진동 |
| 피해 | 지금 총의 4초치 화력(총열 × 연사 × 위력, 최소 위력 × 20) × 웨이브 체력 배율. 일반 적은 대부분 쓸려 나가고 보스는 40%만 받아 체력의 5분의 1 안팎 |
| 모양 | 충격파에 총열 N × 3개의 빛줄기. 가득 차면 내 기체에 금빛 기운이 맥박치고, HUD 대시 게이지 아래에 N-BURST 게이지 |
| 필살기 피해는 게이지를 채우지 않는다 | 연쇄 발동 방지 |

실측(봇, 시드 5개): 첫 발동 3웨이브 무렵, 뒤로 갈수록 웨이브마다 한 번쯤. 수치는 `data.js` `ULT`.

### 5.5 점수
적 처치 점수 × (1 + 보스 처치 수 × 0.5) × 콤보 배율(5.9). 보스 처치 +1000. 기록은 5.9.

### 5.7 소리 (파일 0개, 전부 WebAudio 합성)
- 총소리: 대역 잡음 "탕" + 저역 잡음 몸통 + 저음 펀치 + 금속성 딸깍. 총열 N이 늘수록 두껍고 낮아진다
- 폭발·보스 격파: 필터를 쓸어내리는 잡음 + 저음
- 배경음악: A단조 4마디 루프(Am-F-C-G) 16스텝 시퀀서. 시작 화면 100BPM(베이스·하이햇만) → 게임 128BPM(킥·스네어·아르페지오) → 보스전 146BPM(진행 변경 + 리드 멜로디)

결과 화면 "얻은 코인"이 0부터 올라가며 세어지고(움직임 줄이기면 바로), 아래에 점수·웨이브·보스·주운 코인·강화 보너스로 나눠 보여 준다.
보통 난이도 첫 보스(5웨이브)쯤 끝난 판이 대략 80~170코인.

#### 상점 (시작 화면 "상점" 또는 "기체 바꾸기", 탭 3개)
| 탭 | 내용 |
|---|---|
| 기체 | 6종 카드: 미리보기·이름·설명·체력/속도/화력/대시 막대. 산 기체는 "고르기", 지금 쓰는 기체는 "사용 중". 사면 바로 그 기체로 바뀐다 |
| 강화 (영구, 5단계) | 체력 +1 (150·300·500·800·1,200) · 공격력 +6% (200·400·700·1,100·1,600) · 필살기 시작 게이지 +12% (120·250·450·700·1,000) · 코인 보너스 +10% (150·300·550·900·1,400) · 줍기 자석 범위 +25% (100·200·350·550·800) |
| 시작 아이템 (한 판용, 종류마다 3개까지) | 방패 80 (처음 맞는 한 대를 막음) · 총열 +1 시작 150 · 필살기 가득 시작 120. 사 두면 다음 판 시작할 때 종류마다 하나씩 자동으로 쓰이고 사라진다. 시작 화면에 "다음 판 시작 아이템: …", 판 시작에 알림 |

- 코인이 모자라면 버튼이 어둡고, 누르면 "코인이 모자라요" + 낮은 소리. 코인은 음수가 되지 않는다.
- 저장 키 `ngun.shop1`: `{v, coins, ship, ships, up, items, missions, mseed, life:{earned, games}}`. 읽을 때 모양을 검사해서 망가진 값은 기본값(코인 0, 코어, 강화 0, 무료 기체만)으로, 강화 단계는 5, 아이템은 3을 넘지 못한다.

#### 게임 중 아이템 (`ITEMS`, `DROP`)
일반 적을 잡을 때마다 먼저 회복(4%, 코어는 6%)을 굴리고, 안 나오면 아래 표를 한 번 굴린다. 보스는 회복 2개 + 코인 6개를 둥글게 흩뿌린다.
회복 말고는 다쳤든 아니든 자석 범위(90px, 줍기 자석 강화로 최대 ×2.25)에서 끌려와 주워진다. 코인은 8초, 나머지는 10초 뒤 사라진다 (3초 전부터 깜빡).

| 아이템 | 처치당 확률 | 모양 | 효과 |
|---|---|---|---|
| 코인 | 9% | 도는 금화 | +3코인 (판 끝 코인에 더함) |
| 방패 | 1.2% | 청록 고리 안 육각 | 다음 한 대를 막는다 (최대 1개). 기체 둘레에 도는 육각 고리 |
| 과열 | 1.5% | 주황 고리 안 겹화살 | 6초 동안 연사 ×2, 기체에 붉은 기운 |
| 자석 | 1.2% | 보라 고리 안 말굽 | 8초 동안 화면의 모든 아이템(회복 빼고)을 끌어옴 |
| 폭탄 | 1% | 빨간 고리 안 폭탄 | 화면의 적 탄 모두 지움 + 260px 안 적에게 필살기 피해의 60% (보스는 최대 체력 5%까지) |

- HUD: 대시·N-BURST 게이지 아래에 켜진 효과를 작은 칸으로 세로로 (방패 · 과열 남은 초 · 자석 남은 초 + 남은 시간 막대).
- 소리: 코인 딩, 방패 켜짐, 방패로 막음, 과열, 자석, 폭탄, 미션 보상, 구입, 못 삼 (모두 합성음, 파일 추가 없음). 방패로 막을 때·폭탄 때 짧은 진동.
- 판 통계 `W.stats`에 `coinPicks`(주운 코인 수) · `coins`(코인 값) · `items`(다른 아이템 수) · `blocks`(방패로 막음) · `bombKills`(폭탄 처치) 추가.

#### 태양계 여행 (`data.js` `JOURNEY`·`PLANETS`, `world.js` `placeOf`, 그림은 `render.js` `PLANET_ART`·`PAINT`)
웨이브 2개마다 다음 행성으로 간다. 명왕성 다음(19웨이브)은 다시 수성이고 "2바퀴"가 붙는다. 새 행성 첫 웨이브엔 알림 "화성 도착!" + 한 줄 설명(행성 색)과 반짝이는 소리, HUD 오른쪽 위 첫 칸에 지금 있는 곳 이름.

- 성능: 행성·달·블랙홀 원반·소용돌이는 장면이 바뀔 때 한 번만 캔버스에 그려 두고 매 프레임 찍기만 한다 (화질은 최대 1.25배로 낮춰 기억 절약, 지금 장면과 흐려지는 앞 장면 그림만 남긴다). 하늘은 1/4 해상도. 매 프레임 `shadowBlur` 없음.
- 적·탄이 잘 보이게 행성은 한 겹 어둡게 덮고(밝은 행성일수록 진하게, `PLANET_ART[].veil`) 화면 가장자리 쪽에 둔다.
- 장면이 바뀌면 1.5초에 걸쳐 새 장면이 떠오르고, 행성은 도착 뒤 천천히 지나간다(초당 2px, 최대 90px). 움직임 줄이기면 별·먼지·행성·소용돌이가 멈춰 있다.

#### 운석 (`data.js` `METEOR`, 난이도 `meteorEvery`·`meteorWarn`)
- 웨이브 시작 2.6초 뒤부터, 난이도 간격(쉬움 5.2 · 보통 4.0 · 어려움 3.2초, ±15%)마다 **내 자리에** 빨간 점선 원(반지름 58px)이 뜨고, 가운데부터 빛이 차오르며 오른쪽 위에서 불꼬리 운석이 내려온다. 예고(쉬움 1.35 · 보통 1.15 · 어려움 1.0초) 끝에 원 안에 있으면 1칸 아프다. 떨어지기 직전 원이 흰색으로 깜빡인다.
- 원 밖으로 나가는 데 가장 느린 기체도 0.37초면 된다 (예고의 절반 아래, 테스트로 지킴).
- 웨이브가 오를수록 간격이 웨이브마다 3%씩 짧아지고(최소 60%), 6웨이브마다 운석이 하나씩 더 떨어진다 (내 둘레 190px 안, 최대 넷). 보스 웨이브는 간격 1.5배.
- 원 안의 일반 적도 피해를 입는다 (적을 끌어들여 맞히는 재미, 보스는 안 맞음). 운석 피해는 필살기 게이지를 채우지 않는다.
- 웨이브의 적을 다 잡으면 새 운석은 없고, 카드 화면이 열리면 남은 예고도 지운다.

#### 돌진이 (`data.js` `ENEMIES.charger`)
